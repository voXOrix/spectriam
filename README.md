# spectriam
Spectriam is an open‑source, portable multi‑radio security and analysis tool for wireless protocols - including Wi‑Fi, Bluetooth Low Energy, and 2.4 GHz ISM RF (nRF24). Built for research, education, and testing of your own systems

>**Important:** Spectriam is intended **only** for testing **your own** systems and for **educational/research** purposes. Do **not** use it to intercept, disrupt, or access wireless communications without authorization

## ✨ Features (What Spectriam can do)

- 📶 **Wi‑Fi**
  - Channel scanning, SSID list, RSSI, security info (as implemented)
  - Packet capture / analysis helpers (depending on firmware version)
  - Optional test modes for controlled research environments

- 🔵 **Bluetooth Low Energy (BLE)**
  - Device scanning (advertising), MAC, RSSI, advertising data
  - Optional connection/characteristic exploration (where supported)

- 📡 **ISM 2.4 GHz / nRF24L01**
  - Channel scanning and activity detection
  - Frame sniffing and logging
  - Replay / emulation modes (controlled, for authorized testing only)

- 🖥️ **User Interface**
  - OLED menu navigation (buttons/encoder)
  - Live status, scan results, packet views
  - Configurable settings (channels, filters, timeouts)

- 💾 **Data export**
  - Serial/USB logging (CSV/JSON)
  - Optional SD card logging (if hardware supports)
